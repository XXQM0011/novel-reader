# 小说阅读器

纯前端小说阅读器，支持 txt 和 epub，书和阅读进度都存在浏览器本地，不需要账号和服务器。

## 在线使用

https://xxqm0011.github.io/novel-reader/

## 桌面版

- 桌面版是独立的 Tauri 工程（`reader-tauri` 仓库），与网页版共用同一份 `index.html`。
- 早期用 Electron 打包，安装包 105.1 MB；为压缩体积已迁移到 Tauri，安装包约 1.3 MB。
- 目前还没有提供公开下载链接，安装包不进 Git 仓库。
- 桌面版和网页版数据互不相通，各自独立存储（IndexedDB 按 origin 隔离）。
- 安装包没有代码签名，Windows 可能提示"未知发布者"。

## 功能

### 导入
- 支持 txt 和 epub 格式。
- txt 自动识别 UTF-8、GBK、UTF-16 编码；二进制文件会被拒绝并提示，不会当成文本渲染。
- epub 解析出章节、封面、自带的 CSS 和字体，全部存入本地。

### 书架
- 封面网格布局（手机 3 列，桌面按断点递增到 6 列），有封面的显示封面图片，没有的用首字 + 色块兜底。
- 底部信息层：书名（最多两行）+ 当前章节行，右下角圆形进度环表示本章阅读比例。
- 分组 tab（全部 / 在读 / 未读）+ 书名搜索，共用一套筛选状态。
- 两种空状态：真没书时提示导入；有书但筛选结果为空时显示「查看全部」按钮，点了清掉筛选恢复完整书架。
- 多选模式：长按书架卡片 550ms 或通过「更多 → 删除书籍」进入；点卡片切换选中（勾选框 + 压暗遮罩），底部操作条实时计数，确认后批量删除。

### 阅读视图
- txt 按换行分段渲染；epub 按 Spine 顺序逐章渲染，书自带的 CSS 和字体注入 Shadow DOM（字号 / 颜色由用户控件穿透）。
- 底部章节导航（上一章 / 下一章），右侧目录面板（点章节跳转）。
- 进度模型：「第几章 + 章内比例」。切章、滚动、返回书架时自动保存，重开自动恢复到上次的位置。
- 调节字号（穿透 Shadow DOM），切换日间和夜间模式。

### 删除
- 单本删除：弹窗确认后清理全部数据（正文、书目、章节、资源、进度）。
- 批量删除：多选模式下确认后串行删除所有选中的书，整个批量只重渲染一次书架。

## 技术栈
原生 JavaScript + IndexedDB + localStorage，`index.html` + `epub.js` 两个文件，无框架、无构建步骤。
`epub.js` 负责解析 EPUB（ZIP 解包、OPF / Spine / 目录、封面、CSS、字体），暴露 `window.NovelEpub`。

### 存储结构

IndexedDB 库 `reader`，版本 4，四个 object store，全部使用外部 key（无 keyPath）：

| store | key | value |
|---|---|---|
| `books` | bookKey | 原始文件字节（ArrayBuffer） |
| `meta` | bookKey | 书目信息（书名、字数、章数、封面、opfDir 等） |
| `chapters` | bookKey | 章节数组（每章含 html / text / chars） |
| `resources` | `${bookKey}::${path}` | 见下 |

**`resources` store 同时存两种东西**：二进制的图片/字体（value 为 `{ blob, mediaType }`）
和文本的 CSS（value 为 `{ text }`）。读取时按有没有 `blob` 字段区分。

这是有意的妥协：再开一个 store 的成本（删书要清 5 处）大于收益。代价是 store 的语义不够纯，
改这块代码时要记得两种 value 形状并存。

### 进度模型

阅读进度按「第几章 + 章内比例」存（localStorage key `reader.pos:${bookKey}`），
txt 书恒为第 0 章。旧版按整本书滚动比例存（`reader.progress:${bookKey}`），
读取时自动迁移到新 key 并删掉旧 key。

## 已知限制
- 书籍正文和阅读进度只保存在当前浏览器的本地存储中，更换设备、浏览器或清除站点数据后不会恢复。
- 不支持跨设备同步，也没有账号或云端备份。
- 不支持全文搜索（书名搜索已有，正文搜索在计划中）和书源导入。
- 浏览器存储空间有限，可保存的书籍数量和体积受当前设备及浏览器配额限制。
- 删除书籍后，正文、元数据和阅读进度会一并删除，无法从应用内恢复。
- 不支持 MOBI、AZW3 等其他电子书格式。
- epub 的作者 CSS 可能包含全局重置，已通过 `!important` 兜底保护字号和颜色，
  但书本身的段落缩进 / 居中等排版意图可能与默认样式冲突。
